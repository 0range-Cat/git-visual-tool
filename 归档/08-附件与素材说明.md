# 08 · 附件与素材说明

> 本项目除代码外还带有一条"内容创作线"：一篇博客 + 一组小红书推广文案。本文说明各素材的内容与用途，供接手者使用或继续运营时参考。

## 2. 博客文章（`博客文章.md`）

- **标题**：《我连 Git 都不会，于是先给自己造了一个"看得见"的 Git》
- **发布日期**：2026-09-13
- **内容**：项目故事文——需求单原文、工具长什么样（配图）、三轮折腾（提交失败/双击闪退/全面审计）、四个版本的开发记录表、"我学到的事"。
- **状态**：已发布。文中引用图片用相对路径 `博客图片/xx.png`，在仓库内阅读时图片可正常显示。
- **性质**：史料，归档时未改动。

## 3. 小红书笔记（`文案/小红书笔记.md`）

- **内容结构**：
  - 3 个备选标题（均 ≤20 字）："不会Git的我，点按钮就能管版本" / "把Git命令变成按钮，边用边学" / "Git报错看不懂？这工具给你翻译"
  - 正文：情绪化开头（"黑窗口太没人情味"）→ 6 张图逐一对应功能点 → 结尾引导 + 话题标签（#Git #效率工具 #编程小白 等 7 个）
  - 图片对应表：6 张图各对应哪个功能点
- **状态**：文案与配图已备齐；发布与否、何时发布由项目所有者决定（截至归档未在本仓库记录发布结果）。

## 4. 史料文件

| 文件 | 性质 | 说明 |
|------|------|------|
| `折腾记录.md` | 开发史料（作者亲笔） | 三轮折腾的完整记录：现象/排查/原因/修复/验证/教训，2026-09-12 定稿；比归档文档更原始、更详细，值得精读 |
| `博客文章.md` | 内容史料 | 2026-09-13 发布的博客全文 |

两份文件归档时**一字未改**；若叙述与代码现状有出入，以代码为准。

## 5. 使用素材时的注意点

1. 截图为作者真实环境，含本机用户名/路径等个人信息，对外发布前请自行评估。
2. 博客图片与文案图片内容有部分重复（都是界面截图），但拍摄批次不同（09-13 vs 09-21），尺寸风格有差异，勿混用图注。
3. 若程序未来升级（如新增按钮），截图与文案中的按钮数量/分组会过时，发布前需核对。
