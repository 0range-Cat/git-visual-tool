## 5. 已知限制（4 条，v1.3 审计确认，均不阻塞使用）

1. 凭据登录窗口由 Git for Windows 管理，工具无法控制；被杀毒拦截需放行。
2. `GIT_TERMINAL_PROMPT=0` 禁终端交互——纯终端登录走不通，必须凭据管理器或 SSH。
3. 日志固定写工具目录；只读目录会写失败（静默）。
4. 进度百分比仅网络操作有效，本地操作只有滚动动画（git 限制）。
