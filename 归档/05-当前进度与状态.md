## 5. 已知限制（5 条，v1.3 审计确认，均不阻塞使用，勿当 bug 修）

1. **凭据窗口不受控**：登录窗口由 Git for Windows 管理器弹出，被杀毒拦截需用户自行放行。
2. **纯终端登录不可用**：`GIT_TERMINAL_PROMPT=0` 防卡死的代价；必须凭据管理器或 SSH。
3. **日志路径固定**：写工具目录，只读目录下静默失败（`_log_line` 吞 OSError）。
4. **本地操作无百分比**：git 进度输出只有网络操作有；本地操作滚动动画。
5. **`_refresh_status` 同步阻塞**：极端场景（卡顿网络盘上的仓库）最多冻 UI 8 秒（timeout 上限）。

另有一条**代码级冗余**备案：`Tooltip` 的 `delay` 参数收了未用（固定 450ms）——v1.3 审计判定外观级、不值得修。
