## 一、这是什么项目

**Git 可视化工具**——一个面向"不会用 Git 的新手"的 Windows 桌面程序（单文件 Python + tkinter，v1.3，1357 行），把常用 Git 操作封装成 37 个功能按钮，点击时展示真实执行的命令、过程与结果，并记录日志、内置使用说明。核心设计理念：**报错要说人话，边用边学**。

## 三、项目文件清单（仓库根目录）

```
git工具/
├── git_visual_tool.py      ← 核心程序（v1.3，1357 行，Python + tkinter，零第三方依赖）

├── 文案/                    ← 小红书推广素材：笔记文案 + 配图 6 张
├── 归档/                    ← 本文件夹：交接归档文档
├── memory/                  ← agent 工作日志（跨会话记录，接手者可选读）
├── .gitignore               ← 运行时文件不入库（git_tool.log 等）
└── .gitattributes           ← 换行符策略（*.bat 强制 CRLF——重要，别删）
```
