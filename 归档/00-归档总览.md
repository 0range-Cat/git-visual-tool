## 一、这是什么项目（30 秒版）

**Git 可视化工具**——面向"不会用 Git 的新手"的 Windows 桌面程序：单文件 Python + tkinter（v1.3，1357 行，**零第三方依赖**），把常用 Git 操作封装成 **37 个功能按钮**，点击时展示真实执行的命令、过程与结果，记录日志、内置使用说明；任何命令失败后自动用中文诊断 9 类新手常见原因并引导下一步。核心设计理念：**报错要说人话，边用边学**。

配套内容创作线：一篇已发布博客（2026-09-13）+ 一组小红书文案（2026-09-21）。

## 三、项目文件清单（仓库根目录，逐个说明）

```
git工具/
├── git_visual_tool.py      ← 核心程序（v1.3，1357 行，Python+tkinter，零第三方依赖）
├── 启动Git工具.bat          ← 双击启动器（UTF-8+CRLF；防假 python；失败不闪退）
│                              ⚠ .gitattributes 锁定其 CRLF 换行，勿删该规则
├── 折腾记录.md              ← 作者亲笔的三轮折腾原始记录（史料，一字未改）
├── 博客文章.md              ← 2026-09-13 发布的项目故事文（史料，一字未改）
├── 博客图片/                ← 博客配图 9 张（01-首次启动.png … 09-使用说明.png）
├── 文案/                    ← 小红书素材：小红书笔记.md + 配图 6 张
├── 归档/                    ← 本文件夹：交接归档文档 9 份
├── memory/agent-log.md      ← AI 结对开发的工作日志（非用户手写，辅助参考）
├── .gitignore               ← 运行时文件不入库（git_tool.log / git_tool_config.json / pycache 等）
└── .gitattributes           ← 换行符策略：*.bat 强制 CRLF（闪退教训的固化），其余 text=auto
```

运行时生成的文件（不入库，删了也无妨，下次运行自动重建）：`git_tool.log`（操作日志）、`git_tool_config.json`（记住上次仓库路径）。
