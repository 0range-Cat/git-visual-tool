## 3. v1.1（09-05）：第一轮折腾——提交总是失败

- **现象**：查看状态、暂存正常，点提交报 `失败：退出码 128`，报错 `Author identity unknown`。
- **排查**：语法检查排除代码错误 → 自动化冒烟测试（临时目录建真实仓库）→ 抓到根因：`git config --global user.name` 为空，这台电脑从未配置 Git 身份。
- **根因**：Git 要求每次提交记录作者（姓名+邮箱），装完 Git 不会自动有；不配置，所有提交必定失败，且报错是英文。
- **修复**：① 新增【配置身份】按钮（自动连续执行两条 config 命令）② 失败自动诊断：分析错误输出，中文提示 6 种新手常见失败原因，"未配置身份"还会弹窗引导 ③ 启动预检：打开工具时检测身份并提前提醒 ④ 修复状态栏中文乱码（utf-8/gbk 降级解码）。
- **验证**：用 `GIT_CONFIG_GLOBAL` 环境变量隔离全局配置做端到端测试，4 项场景全过。
- **沉淀原则**："给新手用的工具，不能假设任何前置知识。"

## 4. v1.2（09-05）：第二轮折腾——双击运行闪退

- **现象**：双击 `启动Git工具.bat`，黑窗口一闪而过。
- **排查**：`where python`/`python --version` 正常 → 把 bat 输出重定向到文件抓到"命令语法不正确" → `od -c` 查文件头发现换行符是 LF 而非 CRLF。
- **根因（三层叠加）**：① cmd 解析批处理必须 CRLF，LF 导致括号块解析错乱直接退出 ② `%errorlevel%` 在括号块里是解析时一次性展开，拿到的是进入前的旧值，python 崩了 pause 也永远不执行 ③ Windows 商店的占位 `python.exe`（假 python）可能骗过 `where` 检查。
- **修复**：bat 重写为无括号块的顺序跳转结构（`if errorlevel 1 goto`），先验证 python 真能跑，保存为 UTF-8 无 BOM + CRLF；Python 侧 `main()` 加兜底 try/except——启动异常写日志 + 弹错误对话框，杜绝"一闪而过"。
- **验证**：字节检查确认 CRLF；实跑 bat 8 秒后 python 进程存活。

## 5. v1.3（09-12）：第三轮折腾——全面审计

这轮不修任何东西，先通读全部代码列疑点，再逐个用实验取证（临时目录 + `GIT_CONFIG_GLOBAL` 隔离，全部离线），按收益/风险排序后只修值得修的。

### 5.1 取证结果（11 个探针）

| 探针 | 结论 |
|------|------|
| A/B/C/M：push 无远程、无上游、远程地址错 | 三类真实报文不在失败提示映射 → 缺口证实 |
| E：自定义命令引号写法 | 引号不配对抛英文报错 → 需修 |
| F/G/H：5000 文件状态刷新 92ms、20MB 日志整读 0.03s、终端插 2 万行 0.85s | 性能无问题 → 不修 |
| I：父进程退出后子进程 | 子进程完整跑完 15 秒 → **孤儿进程实锤** |
| J：离线 bundle 克隆全链路 | 53 个进度事件 0→100% → 健康 |
| K：带引号路径 | `isdir` 返回 False → 误判证实 |
| L：带令牌 URL 的命令显示 | 令牌明文出现在预览/终端/日志 → **泄露证实** |

### 5.2 修了什么（每项修完立刻测试）

1. **关窗孤儿进程**：关窗前弹确认，确认后终止命令再退出；顺带修掉一个竞态——`stop()` 读进程句柄时命令可能还没启动完成，改为停止请求标志位 + 启动完成后补杀。三个场景（启动瞬间关窗/运行中关窗/选取消）用文件系统证据验证。
2. **失败提示补齐 3 类**（push 无远程 → 引导【添加远程】+【推送并关联】；分支无上游 → 引导【推送并关联】；远程地址错 → 引导【查看远程】核对）。
3. **带引号路径误判**：新增 `norm_path()` 统一规整，配置文件也存干净路径。
4. **URL 凭据明文暴露**：显示层（预览/终端/日志）把 `https://user:token@...` 打码为 `https://***@...`；只改显示，真实执行的参数原样。
5. **自定义命令引号不配对**：退化为按空格拆分 + 中文提醒。

### 5.3 明确不修的（证据不支持）

状态栏三次 subprocess 调用（92ms）、历史日志整读、终端行数无上限、克隆进度链路、若干外观小瑕疵。审计纪律："证据不支持的不动，不为优化而重构正常工作的代码。"

### 5.4 审计插曲

回归测试一度 5/11、13/14，排查后全部是**测试脚本自身的错误**；某次测试忘打弹窗补丁，真实的"配置身份"引导窗口弹出，被人工点完——意外完成一次真人端到端验证。
